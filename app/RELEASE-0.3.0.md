**NoteVive 0.3.0 — préversion Windows réservée aux dictées fictives.** Télécharger **NoteVive-Windows-x64-Essai.zip** et son fichier `.sha256`, vérifier l’empreinte, extraire le ZIP en entier, puis ouvrir **NoteVive.exe**. Le modèle est inclus et fonctionne hors ligne ; aucun Python ni runtime C++ n’est à installer. L’EXE n’est pas signé.

Cette version remplace Zipformer par Whisper Large-v3 Turbo Q5_0, whisper.cpp 1.8.5, OpenBLAS 0.3.34 et Silero GGML 6.2, avec détection de pause à 576 ms. La dictée s’exécute sur le processeur et exige Windows 11 x64 avec AVX2 et ses extensions associées. Si le poste est incompatible, NoteVive garde l’accès aux notes sans charger le modèle ni ouvrir le micro. Le moteur est isolé dans un processus supervisé. Le texte déjà reçu reste disponible après une interruption ; un message signale les passages à reprendre.

La bibliothèque ajoute dossiers et sous-dossiers, renommage, classement par bouton « Classer… », recherche dans le titre et le texte, tri et dates de création/modification. Elle préserve les notes historiques du même compte Windows. Les fichiers sont chiffrés par DPAPI localement. Aucun audio du microphone n’est enregistré. L’insertion dans un champ d’un autre logiciel n’est pas encore implémentée ; F9 commande la dictée dans NoteVive.

Le [benchmark détaillé](https://github.com/sarbhakan/DocTranscript/blob/main/p0/asr_benchmark.md) compare cinq modèles sur 89 WAV. Le profil par pause améliore les doses et les fractions par rapport à UltiMed par pause sur le lot difficile, mais les négations strictes régressent et des ajouts indésirables restent observés. Le P95 estimé fin de parole → résultat atteint 4,20 s sur Mac M1 Pro ; il dépasse l’objectif de 2 s et n’est pas une mesure Windows. Le catalogue de 70 517 libellés est consultable, sans correction automatique de la dictée. La BDPM est exclue du paquet public.

La [CI Windows](https://github.com/sarbhakan/DocTranscript/actions/runs/43620136119/job/132523751821) valide le stockage, la reprise après panne, le silence, les trois contrôles chiffrés et le parcours automatisé de création, recherche, tri, classement et réouverture des notes. Ces tests n’utilisent pas de microphone réel. Les [mesures du banc](https://github.com/sarbhakan/DocTranscript/blob/main/docs/p0-choix-moteur.md) montrent une latence supérieure aux objectifs. Il reste à suivre la [recette au micro et à l’écran](https://github.com/sarbhakan/DocTranscript/blob/main/docs/windows-recette-030.md) sur deux PC physiques, dont un poste compatible à 8 Go sans GPU dédié.

Le fichier `.sha256` permet de contrôler l’archive téléchargée. Les sources, notices MIT, attributions du catalogue, versions et empreintes des modèles figurent dans le dépôt et dans le ZIP. Les archives « Source code » ajoutées par GitHub ne contiennent pas l’EXE.
