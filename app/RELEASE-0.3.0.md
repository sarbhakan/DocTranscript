Projet de notes de préversion : **le ZIP Windows 0.3.0 n’est pas encore publié**. Il est réservé aux dictées fictives. Lorsqu’il sera disponible, extraire entièrement **NoteVive-Windows-x64-Essai.zip**, puis ouvrir **NoteVive.exe**. Le modèle est inclus : aucune connexion, installation de Python ou installation de runtime C++ n’est nécessaire pour dicter. L’EXE n’est pas signé.

Cette version remplace Zipformer par Whisper Large-v3 Turbo Q5_0 et Silero GGML 6.2, avec détection de pause à 576 ms. La dictée exige Windows 11 x64 et un processeur compatible AVX2 et ses extensions associées ; elle fonctionne sans GPU dédié. Si le poste est incompatible, NoteVive garde l’accès aux notes sans charger le modèle ni ouvrir le micro. Le moteur est isolé dans un processus supervisé. Le texte déjà reçu reste disponible après une interruption ; un message signale les passages à reprendre.

La bibliothèque ajoute dossiers et sous-dossiers, renommage, classement par bouton « Classer… », recherche dans le titre et le texte, tri et dates de création/modification. Elle préserve les notes historiques du même compte Windows. Les fichiers sont chiffrés par DPAPI localement. Aucun audio du microphone n’est enregistré. L’insertion dans un champ d’un autre logiciel n’est pas encore implémentée ; F9 commande la dictée dans NoteVive.

Le [benchmark détaillé](https://github.com/sarbhakan/DocTranscript/blob/main/p0/asr_benchmark.md) compare cinq modèles sur 89 WAV. Le profil par pause améliore les doses et les fractions par rapport à UltiMed par pause sur le lot difficile, mais les négations strictes régressent et des ajouts indésirables restent observés. Le P95 estimé fin de parole → résultat atteint 4,20 s sur Mac M1 Pro ; il dépasse l’objectif de 2 s et n’est pas une mesure Windows. Le catalogue de 70 517 libellés est consultable, sans correction automatique de la dictée. La BDPM est exclue du paquet public.

Le [test Windows avec OpenBLAS](https://github.com/sarbhakan/DocTranscript/actions/runs/43612396023) passe la construction, le stockage, les scénarios de panne et les contrôles audio du paquet. Le premier extrait de 6,44 s demande 14,74 s, démarrage compris. Les deux cas de régression passent les contrôles de doses et fractions, mais un nom de médicament n’est pas reconnu. L’interface reste à confirmer après un échec du script de recherche du dossier parent. Ces tests n’utilisent pas de microphone réel. Les essais sur les deux PC physiques, dont un poste compatible à 8 Go sans GPU dédié, restent nécessaires : [recette et phrases fictives](https://github.com/sarbhakan/DocTranscript/blob/main/docs/windows-recette-030.md). Cette préversion n’est pas qualifiée pour des données patient ni un usage clinique.

Le fichier `.sha256` permet de contrôler l’archive téléchargée. Les sources, notices MIT, attributions du catalogue, versions et empreintes des modèles figurent dans le dépôt et dans le ZIP. Les archives « Source code » ajoutées par GitHub ne contiennent pas l’EXE.
