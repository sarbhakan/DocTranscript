# Composants inclus dans le paquet d’essai Windows 0.3.0

- [whisper.cpp v1.8.5](https://github.com/ggml-org/whisper.cpp/releases/tag/v1.8.5), auteurs ggml, avec son moteur CPU ggml. Le paquet distribue le résultat compilé pour Windows, sous [licence MIT](https://github.com/ggml-org/whisper.cpp/blob/v1.8.5/LICENSE), jointe dans `Whisper-cpp-MIT.txt`.
- La variante AVX2 en essai utilise [OpenBLAS 0.3.34](https://github.com/OpenMathLib/OpenBLAS/releases/tag/v0.3.34), bibliothèque de calcul compilée statiquement sans LAPACK ni Fortran, sous licence BSD à trois clauses jointe dans `OpenBLAS-BSD.txt`. Les compilations de référence sans OpenBLAS peuvent utiliser les [multiplications matricielles llamafile de GGML](https://github.com/ggml-org/whisper.cpp/blob/v1.8.5/ggml/src/ggml-cpu/llamafile/sgemm.cpp), Copyright 2024 Mozilla Foundation, sous licence MIT jointe dans `Llamafile-MIT.txt`.
- [Whisper Large v3 Turbo](https://huggingface.co/openai/whisper-large-v3-turbo), poids d’OpenAI sous [licence MIT](https://github.com/openai/whisper/blob/v20250625/LICENSE), jointe dans `Whisper-OpenAI-MIT.txt`. Le fichier multilingue `ggml-large-v3-turbo-q5_0.bin` est une [conversion GGML quantifiée Q5_0 par Georgi Gerganov](https://huggingface.co/ggerganov/whisper.cpp/commit/98aa99a0a9db05ae2342309f5096248665f7cba3), déjà fournie sous MIT ; NoteVive ne modifie pas les octets de cette conversion.
- [Silero VAD v6.2](https://github.com/snakers4/silero-vad/tree/v6.2), Silero Team, sous [licence MIT](https://github.com/snakers4/silero-vad/blob/v6.2/LICENSE), jointe dans `Silero-VAD-MIT.txt`. Le fichier `ggml-silero-v6.2.0.bin` est la [conversion GGML publiée sous MIT par ggml-org](https://huggingface.co/ggml-org/whisper-vad/commit/9ffd54a1e1ee413ddf265af9913beaf518d1639b), par Georgi Gerganov et Kitaiti Makoto ; NoteVive utilise ce fichier tel quel.
- Les exécutables `NoteVive.exe` et `NoteVive-ASR.exe` sont construits avec [Zig 0.15.2](https://ziglang.org/download/) pour Windows x64. Ils incorporent du code des bibliothèques C++ LLVM (libc++, libc++abi et libunwind, Apache 2.0 avec exceptions LLVM), du runtime de compilation fourni avec Zig (voir `Zig-compiler-rt-MIT.txt`) et du démarrage Windows de [MinGW-w64 13.0.0](https://github.com/mingw-w64/mingw-w64/tree/v13.0.0). Les textes livrés par Zig et la [notice amont de redistribution du runtime MinGW-w64](https://github.com/mingw-w64/mingw-w64/blob/v13.0.0/COPYING.MinGW-w64-runtime/COPYING.MinGW-w64-runtime.txt) figurent dans `Licences/cxx-runtime`.
- [SQLite 3.54.1](https://sqlite.org/releaselog/3_54_1.html), [domaine public selon le projet](https://sqlite.org/copyright.html), compilé pour la consultation locale du catalogue. Les notes ne sont pas stockées dans ce fichier SQLite.
- Catalogue de libellés : l’attribution, l’édition, la licence et les transformations de chaque source figurent dans `Referentiels.json`. L’index de recherche est une dérivation technique ; les libellés affichés restent ceux des sources. Le paquet 0.4.1 ajoute les dénominations, substances, formes et voies du RUIM de l’ANSM, sous Licence Ouverte 2.0, ainsi que l’ADICAP et la LAHN. Il ne contient pas d’extrait des fichiers BDPM. Les doses éventuellement présentes dans un libellé officiel ne sont ni un conseil de prescription ni des données injectées au moteur. Le catalogue est consultable et ne modifie pas la dictée ; il n’indique pas la disponibilité des produits ni les règles de facturation.

Les notices des modèles et moteurs et le manifeste des référentiels figurent aussi dans le dossier `Licences`. Les outils de construction ne sont pas distribués dans le ZIP.
